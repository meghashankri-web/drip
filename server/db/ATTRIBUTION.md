# Data & asset attribution

- **ZIP code coordinates** (`zip_locations.csv`): derived from the GeoNames US postal code dump
  (https://download.geonames.org/export/zip/), licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Reduced to zip, lat, lng, city, state.
- **Seed avatars**: generated with [DiceBear](https://www.dicebear.com/) using the "Personas" style
  by Draftbit (https://personas.draftbit.com/), licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- **Seed users** in `seed-data.json` are fictional. Any resemblance to real people is coincidental.
